## Overview

Notes keeps what you know about a server next to the server. Each host gets as many notes as you want, written in markdown. Open them in a full tab, or in a panel beside the SSH terminal so the command you wrote down is one click from the prompt.

Read the [docs](https://docs.termix.site/plugins/notes) to set it up and use it.

<br />

## Features

- Many notes per host, per folder, or private to you
- Write and preview with a small toolbar, task lists and tables
- Copy a command from a code block or send it to the open terminal
- Pin notes, add tags and search every note you can open
- A notes panel beside any SSH terminal
- Anyone with access to a host can read its notes, edit access is needed to change them
- Actions to list, read, create and add to notes for the assistant and automations

## Support

Bugs and ideas for Notes go in this repo: [report a bug](https://github.com/Termix-SSH/Plugin-Notes/issues/new?template=bug_report.yml) or [request a feature](https://github.com/Termix-SSH/Plugin-Notes/issues/new?template=feature_request.yml). Report an issue on the plugin's page in the Plugins tab fills in your versions for you.

Problems with Termix itself (login, hosts, credentials, sharing, sync) go in the [Termix repo](https://github.com/Termix-SSH/Termix/issues/new/choose). Not sure where it goes? Open it there and it will be moved.

Add as much detail as you can, in English if possible. For questions, join the [Discord](https://discord.gg/jVQGdvHDrf) server.
